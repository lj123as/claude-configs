## Adding Custom Skills

1. Create a folder in `_custom/` with your skill name
2. Add `SKILL.md` with documentation
3. Include any supporting files

Example structure:

```
_custom/
└── my-code-reviewer/
    ├── SKILL.md
    ├── LICENSE.txt (optional)
    └── scripts/
```
